# INC-001: `w1pTime_continuous_in_H` の偽な一般化と release 前 soundness postmortem

- **Incident ID:** INC-001
- **Date and environment:** 2026-06-17（スキャフォールド導入）〜2026-07-19（独立再レビュー完了）．中心的な検出補助事象は 2026-06-28（vps，session `90fa24bb`，leray-hopf 当時の repo 名 lean-pde）．発覚・修正・postmortem 本体は 2026-07-16〜07-19（GitHub Issue/PR ベース，実行ホスト未特定）．対象は leray-hopf メインリポジトリ
- **Trigger:** 2026-06-17 のスキャフォールド導入コミット（4-stream scaffold，"gate-approved statement layer" と自称）で，`LerayHopf.Bochner.w1pTime_continuous_in_H` が汎用 `{p q} (hpq : 1 ≤ p ∧ 1 ≤ q)` 型の public `sorry` として導入された
- **Immediate symptom:** 2026-07-16 の release 前レビュー（issue #158）で，`H = ℓ²` 上の重み付き Hilbert triple とスパイク列による陽な反例が構成された．`p = q = 1` は現行の仮定 `1 ≤ p ∧ 1 ≤ q` を満たすが，`u ∈ L¹(0,T;V)` かつ `u' ∈ L¹(0,T;V')` でも H-連続な a.e. 代表元が存在しない例が作れるため，現行の型は偽と確定した
- **Underlying cause:** 実際に検討・証明されていた proof spike は `p = q = 2`（issue #4 の Lions–Magenes spike，energy pairing の limit passage が `L²(V') × L²(V)` の Cauchy–Schwarz に依存）のみだったが，public theorem の汎用シグネチャはそれと同期して狭められなかった．「個々の Bochner integrand の可積分性」と「エネルギー恒等式の dual pairing `⟨u',u⟩` の可積分性」が混同され，後者を保証しない仮定のまま generic API として公開され続けた
- **Affected theorem, file, or campaign:** `LerayHopf.Bochner.w1pTime_continuous_in_H`（`TimeSobolev.lean`，のち `TimeSobolevExperimental.lean` へ分離），`lean-pde-notes` corpus の対応 annotation，および `STATUS.md`／`architecture.md`／`pdelib-staging.md` 等の設計文書．当該宣言は capstone の critical path 外（2026-06-28 時点で dead/unused と判定済み）であり，証明済み capstone（axiom-free）自体への影響はない
- **Why existing checks failed:** (1) `sorry` 付き public specification の型を独立に精査する statement review が一度も行われず，elaboration の成功と「`sorry` を正直に表示していること」が主張の正しさの代わりに扱われた．(2) 2026-06-28 の直接攻撃キャンペーン（session `90fa24bb`）はこの宣言を「最終4公理が収束する共有基盤」と位置づけて数時間規模の攻撃を組んだが，反射ルート循環（B1 が構築対象そのものを要求する）に行き詰まった直後，1分程度の再検証で「実装のどこからも参照されていない（docstring のみ）」という consumer verdict を下し，型の soundness には踏み込まないまま計画を破棄・redirect した．(3) notes corpus 側は source docstring をそのまま追認する self-referential verification に陥り，誤った主張をより自信ある日本語で再掲した．(4) 大量のスキャフォールド・annotation の batch review で theorem 単位の文献照合が希薄化した
- **How the problem was detected:** 2026-07-16，公開前の soundness postmortem（issue #158）における独立レビューで，`p = q = 1` の陽な反例が構成され偽と確定した
- **Recovery procedure:** PR #162（07-17T00:25–01:01Z）で theorem を `LerayHopf.Experimental` に分離し，signature を `p = q = 2` に制限する修正（fix commit, 07-17T00:51Z）を含めてマージ．PR #164（同日 01:06–01:13Z）で周辺文書の矛盾記述を解消．直後のマージで生じた doc-comment 構文エラー（`/--` が後続宣言を失い parse error）を PR #169（02:46–05:12Z）でホットフィックス．PR #170（07:09–11:12Z，codex pre-review 経由）で postmortem 文書・statement-gate 政策・6件の `ALLOW_SORRY` 宣言全てに対する statement card・回帰guard スクリプト `check-statement-cards.sh` を導入し，2種類の合成違反（汎用シグネチャへの回帰／card 欠落）を実際に発生させて guard が red になることを確認したうえで revert．PR #177（07-19T09:29–09:34Z，requested reviewer 0・submitted review 0 でマージ）で notes/source の関数空間表記と文献 locator を訂正したが，独立レビュー抜きでの merge という同種の handoff-failure を再演し，issue #178（同日 10:22–15:49Z）で残存する誤記（`TimeSobolevExperimental.lean` の doc comment/TODO 中の誤った関数空間表記2箇所，`hT` の役割説明の数学的不正確さ）を検出・修正し，独立レビューを完了した
- **Permanent guardrail introduced:** `scripts/check-statement-cards.sh` を CI（`lean.yml` の guards job と `release-attestation.yml`）に組み込み，(a) `w1pTime_continuous_in_H` の汎用 `{p q}` シグネチャへの回帰，(b) `ALLOW_SORRY` 宣言の statement card 欠落を検出する．`docs/statement-gates.md` で elaboration／axiom／semantic の3独立 gate，exponent-parametric theorem への adversarial substitution 要件（weighted ℓ²／spike／noncomplete／nonmeasurable の反例チェックリスト），special-case-proof ⇒ special-case-API 規則，blind review 要件，batch review と mathematical review の分離を政策化した
- **Generalisable lesson:** `sorry` 付き public API の「未証明であることの正直な表示」は，主張の型が正しいことを何ら保証しない．証明が特殊ケース（`p = q = 2`）でしか検討されていないなら，公開する型もそのケースに限定しなければならない．「著名な定理名」（Lions–Magenes）や「隣接箇所での statement-gate 成功体験」は，当該宣言自体の独立した型検査の代替にならない．そして本インシデントの事後対応自体（PR #177 の無レビューmerge）が示す通り，postmortem・政策導入の直後であっても「独立レビュー必須」の運用は一度で定着せず，低優先度・doc-only に分類された PR から同型の handoff-failure が再発し得る
- **Primary evidence:** EV-0925（session `90fa24bb`，2026-06-28T07:35–07:59Z の直接攻撃・反射ルート循環発見・consumer verdict），`evidence/repository-snapshots/leray-hopf/issues.json`（issue #158・PR #162/#164/#169/#170/#177・issue #178 の全文），`evidence/repository-snapshots/leray-hopf/commits.json`（スキャフォールド導入コミットと fix commit のタイムスタンプ）

- **Confidence of reconstruction:** medium〜high．issue #158/#170/#177/#178 の本文と関連 PR は GitHub snapshot（primary）から全文確認済みで，2026-06-28 の consumer verdict は session ログ（EV-0925）と当該コミットのタイムスタンプ（07:59 台）が独立に一致し裏付けられる．一方，2026-06-17 のスキャフォールド導入時セッション自体は未特定（コミット記録のみが一次資料）であり，2026-07-16〜19 の修正作業を実行したホスト・セッション ID も本カードの資料からは確定できないため medium とする
