## 経緯（詳細）

2026-06-20，`LerayHopf/TorusConvectionForm.lean` を sorry-free 化する作業の最終段階として，ファイル最後の `sorry` であった `galerkinConvection_antisymm`（box-truncated な T³ 対流形式の反対称性）の証明が進められていた．著者（lean-prover 役のエージェント）は，この命題を無制約の `v, w : L2Sigma` について証明しようと 2 度試み，いずれも行き詰まって撤回した．この過程で `ALLOW_SORRY` の placeholder が，実際には成立しない（偽の）命題の上に残されたまま，PR #27 として提出された．

2026-06-21T02:58（UTC），独立アジュディケータ（adversarial review 役のエージェント）が PR #27 をマージ前レビューし，box-truncated antisymmetry を無制約の `v, w` について数値的に検証した．結果，具体的な `v, w` の組に対して両辺の数値差が 80.7 に達する反例が構成され，主張が偽であることが確定した．一方，`v, w` を有限 Fourier 台への射影で不変な部分空間 `Vₙ`（`velocityProjection_n n v = v` かつ `velocityProjection_n n w = w`）に制限した場合には，数値誤差 1e-13 で成立することも同時に確認された．著者自身も，先行 2 revision がいずれも unsound だったことをこの時点で認めた．

2026-06-21T03:14，修正が実施された．`galerkinConvection_antisymm` の signature に `velocityProjection_n n v = v` と `velocityProjection_n n w = w` の 2 仮定を追加して主張を `Vₙ` に制限し，各固定 `k` について内側の `l`-和を `fourierBox n` から `σ_k`-不変な部分集合へ制限（係数が箱の外で消えることを利用），`Finset.sum_nbij'` による対合 `l ↦ -(k+l)` でのインデックス入れ替え，`lₐ + (-(k+l))ₐ = -kₐ` の組み合わせ，`DivFreeL2 u` による発散消去，という手順で証明を完成させた．`ALLOW_SORRY` を除去し，`check-no-sorry.sh`／`check-no-axiom.sh`／`check-theorem-names.sh` と `lake build` の green を確認の上，同日中に PR #27 をマージした．新規公理はゼロで，`torus3_NSForms_exist` は残存するが，この antisymmetry には依存しない状態になった．

本件は，ビルド成功・sorry-free 化という機械的なゲートだけでは捕捉できない soundness 上の欠陥を，数値反例テストを伴う独立の adversarial review がマージ前に検出・修正した事例である．
