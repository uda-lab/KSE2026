## 経緯（詳細）

2026-06-20，`LerayHopf/TorusConvectionForm.lean` を sorry-free 化する作業の最終段階として，ファイル最後の `sorry` であった `galerkinConvection_antisymm`（box-truncated な T³ 対流形式の反対称性）の証明が進められていた．著者（lean-prover 役のエージェント）は，この命題を無制約の `v, w : L2Sigma` について証明しようと 2 度試み，いずれも行き詰まって撤回した．この過程で `ALLOW_SORRY` の placeholder が，projection closure 仮定を欠く signature の上に残されたまま，PR #27 として提出された．

2026-06-21T02:58（UTC），独立アジュディケータ（adversarial review 役のエージェント）が PR #27 をマージ前レビューし，意図した Fourier 和の再添字付けには `v, w` が有限 Fourier 台への射影で不変な部分空間 `Vₙ` に属することが必要であり，無制約 signature にはその closure 条件が欠けると指摘した．無制約入力で両辺の数値差 80.7，`Vₙ` 制約下で 1e-13 という評価は，この構造的診断を補強する近似的観測として記録されたもので，certified counterexample ではない．著者自身も，先行 2 revision がいずれも unsound だったことをこの時点で認めた．

2026-06-21T03:14，修正が実施された．`galerkinConvection_antisymm` の signature に `velocityProjection_n n v = v` と `velocityProjection_n n w = w` の 2 仮定を追加して主張を `Vₙ` に制限し，各固定 `k` について内側の `l`-和を `fourierBox n` から `σ_k`-不変な部分集合へ制限（係数が箱の外で消えることを利用），`Finset.sum_nbij'` による対合 `l ↦ -(k+l)` でのインデックス入れ替え，`lₐ + (-(k+l))ₐ = -kₐ` の組み合わせ，`DivFreeL2 u` による発散消去，という手順で証明を完成させた．`ALLOW_SORRY` を除去し，`check-no-sorry.sh`／`check-no-axiom.sh`／`check-theorem-names.sh` と `lake build` の green を確認の上，同日中に PR #27 をマージした．新規公理はゼロで，`torus3_NSForms_exist` は残存するが，この antisymmetry には依存しない状態になった．
